# Tokens as Locality-Preserving Anchors: Scalable Novel View Synthesis with Target-Adaptive Token Routing

Project page for the paper by Sagnik Ghosh and Aswin C. Sankaranarayanan (Carnegie Mellon University).

- Paper: https://arxiv.org/abs/2611.31156
- The page is static: open `index.html` in a browser, or serve this folder with any static web server.
- `viewer/` holds the interactive video viewer linked from the page.

Page design adapted from the [Solv3R project page](https://ubc-vision.github.io/solv3r/).
